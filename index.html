这个工具必须通过本地服务器打开

浏览器不允许在 file:// 下加载 ES Module， 所以直接双击 index.html 会看到空白页（地图也不会出现）。

在工具目录里任选一种方式启动：

双击 start.cmd
或  node server.mjs
或  npm start

然后访问 http://127.0.0.1:5273/（如果换了端口，用它打印出来的地址）。
